## 📌 Project Overview

This is a **Looker Studio dashboard connected to a Google Sheet**. It tracks **actual revenue, profit, actual cost and expenditure** by **product** and by **country**, compares **payment gateways** to see which one suits customers best, and uses a **world map** to show sales revenue by country.

## 🎯 Business Questions Answered

| Question | Where to find it |
|---|---|
| How much revenue and profit are we making? | Revenue and profit KPI cards |
| What are the actual cost and expenditure? | Actual cost and expenditure KPI cards |
| Which products perform best? | Product wise charts |
| Which countries bring the most revenue? | World map and country wise charts |
| Which payment gateway suits customers best? | Payment gateway comparison |

## ⚙️ How I Built It

```text
Sales data in Google Sheets  →  Connect to Looker Studio  →  KPI cards, charts and world map  →  Business recommendations
```

1. **Data source:** kept the sales data in a **Google Sheet** and connected it to **Looker Studio**, so the dashboard reads from the sheet.
2. **Track money:** built views for **actual revenue, profit, actual cost and expenditure**, by product and by country.
3. **Compare gateways:** compared payment gateways to see which one customers prefer.
4. **Map it:** added a **world map** that shows sales revenue by country.
5. **Recommend:** turned the findings into the actions listed below.
